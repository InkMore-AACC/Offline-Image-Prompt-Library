# 离线图片与提示词管理库

版本：`1.1.0+codex.20261108`。

选择一个本地图片文件夹，在 Codex 右侧浏览图片、管理标签和长提示词，按需分析或创作。不依赖 Eagle。

安装必须使用仓库根目录的安装器，它负责填写当前电脑的 Python 和脚本路径。不要直接使用发布包里的 .mcp.json 路径模板。

完整安装、功能和故障说明：[项目主页](https://github.com/InkMore-AACC/Offline-Image-Prompt-Library)。安装后新建 Codex 任务，说“打开离线图片与提示词管理库”。

## 随插件发布的参考素材

完整仓库安装包随附 `plugin/assets/image2.5参考`：541 张原图及 `manifest.json` 中的名称、标签和完整提示词。安装器复制这些随附素材并校验原图 SHA-256；安装后选择自己的图库，点击“导入随附参考素材”，即可导入平铺的 `image2.5参考` 文件夹。相同内容跳过；同名不同内容保留并另起文件名；导入不会覆盖已有修改。

请下载 GitHub 完整仓库 main.zip，素材随该安装包发布；旧 downloads 目录的小安装包不再作为发布入口。随附图片和提示词用于参考，其权利仍属于原作者，随附不构成额外授权。

## 1.1.0：小红书图片与提示词分享库

- 新增2169张小红书原图及对应中文名称、公开提示词、标签、作者、来源链接和使用条件。原图不重新压缩，同时保留原有541张 image2.5参考。
- 下载完整仓库安装包并运行安装器。选择自己的图库后，点击“导入小红书提示词库”；原有“导入随附参考素材”仍用于 image2.5参考。重复素材跳过，已有修改保留，不会自动导入或替换自己的图库。
- 不使用Codex的朋友，可直接打开 `plugin/assets/小红书提示词库` 中的图片，在“提示词文本”目录打开同名TXT；机器可读资料见manifest.json，作者与来源见来源资料.json。
- 只分享小红书素材时，完整复制 `plugin/assets/小红书提示词库` 即可，图片与资料全部在此；本机登录信息、采集工具、运行配置和选图记录不在发布包内。
- 修复Windows后台服务启动时出现控制台窗口的问题，保留原服务生命周期行为。
