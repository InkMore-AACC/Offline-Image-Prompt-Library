# 小红书图片与提示词库

共2169张原图，按发布时的本地图库导出，包含中文名称、提示词、标签、作者、笔记来源和使用条件。图片保留原始字节，不裁切、不重新压缩。一张原始文件计一张素材。

- 使用插件：安装完整仓库包，打开图库并选择接收文件夹，点击“导入小红书提示词库”。导入时保留已有修改，重复素材跳过。
- 直接使用：打开原图，并在“提示词文本”文件夹打开同名TXT；其中包括标签、来源和提示词说明，无需安装Codex。
- `manifest.json`是机器可读的完整资料清单；`来源资料.json`保留作者与笔记来源；`资料核验.json`记录导出数量与原图校验。
- 需要参考照片、风格图或填入主题的模板，使用时须补齐输入。原作者指令与成品的已知差异见同名TXT中的说明；没有把设计说明或自行反推结果冒充作者原词。
