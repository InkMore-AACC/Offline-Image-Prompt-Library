提示词：
建筑与景观竞赛展板风格的用户群体活动行为分析图 / User Groups Analysis。白色背景，采用6个独立且统一规格的分析模块，2行×3列整齐排布，每个模块对应一种用户群体。每个模块由“用户群体英文标题 + 环形24小时活动时间图 + 人物行为剪影 + 活动文字标签”组成。中心使用简洁的时钟/时间轴结构，以扇形色块和细刻度表达该人群不同时间段的使用强度与活动偏好，重点时段通过半透明扇形区域突出。时钟下方布置2–4个简洁的人物剪影，表现该人群典型活动行为，并在人物下方标注简短活动名称，
【例如】“休憩 / RELAX”“散步 / WALK”“社交 / SOCIAL”“运动 / EXERCISE”“亲子活动 / FAMILY FUN”“购物 / SHOPPING”等。6组用户可设置为：运动爱好者 Sports Enthusiast、年轻家庭 Young Family、城市青年 Urban Millennial、商务人群 Business、空巢老人 Empty Nester、学生 Student。不同用户组采用不同但低饱和的单色体系区分，如砖红、橙色、浅绿色、绿色、蓝绿色、灰蓝色；人物剪影与时间图保持同色系。整体采用建筑竞赛信息图 / 建筑分析图 / 矢量插画风格，细灰色线条、极简几何图形、低饱和配色、清晰留白、统一字体、版式严谨，避免真实照片、复杂场景、建筑透视和装饰性背景。整体效果参考专业建筑事务所竞赛展板，强调“不同人群—时间分布—行为活动”的信息表达，画面干净、专业、易读。

使用条件与原词说明：
原作者环形活动时间模板，用户类别和活动可按实际需求改填。
