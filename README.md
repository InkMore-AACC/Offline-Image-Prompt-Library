# 离线图片与提示词管理库

浏览本地图片，管理标签与提示词，辅助分析和创作。

## 下载与安装

[下载独立安装包](https://github.com/InkMore-AACC/Offline-Image-Prompt-Library/raw/refs/heads/main/downloads/offline-image-library-1.0.0.zip)。完整解压后双击 `安装插件.cmd`；首次使用选择自己的图片文件夹。

这是独立的离线插件。Eagle 版位于另一个仓库：[Eagle-2-Codex](https://github.com/InkMore-AACC/Eagle-2-Codex)。

## 打开

在 Codex 中说“打开离线图片与提示词管理库”。新版独立运行在127.0.0.1:18766，Eagle版仍在18765。每个对话使用自己的task参数，不复制其他对话完整网址。首次使用点击“选择图库文件夹”，也可直接告诉Codex本地文件夹路径。

安装包只包含插件程序、Skill、安装器和测试，不包含图片、提示词资料、个人配置或任务选择记录。安装后请选择自己的图片文件夹。离线版与 Eagle 版互相独立，不自动同步图片或元数据。

## 文件与资料

图片和子文件夹位于你选择的图库根目录。可见的“图库资料”目录保存素材信息.json、元数据备份、缩略图缓存和任务选择。不要只备份图片，搬家时复制整个图库根目录。

保存先写临时文件再替换，保留一份上次索引。长提示词已通过百万字符级别保存、重启重读及HTTP回读测试；单次HTTP提交上限64 MiB，不设置原 Eagle 版的10万字符限制。提示词在磁盘上是UTF-8文本，页面仅显示摘要，编辑读取全文。

图库后台每2秒扫描文件，页面每3秒检测变化。文件连续两轮尺寸及修改时间一致后读取；支持 JPG/JPEG、PNG、WebP、GIF、BMP、TIFF、ICO、AVIF（以Pillow解码支持为准）。其他文件保留但不展示；不跟随符号链接和目录联接。资料目录不参与扫描。

新图生成本地缩略图和颜色统计，不调用AI。文件改名或在库内移动时，仅在内容唯一对应时保留身份和资料；重复图片无法唯一判断时保留旧资料并提示，不乱配。图片持续缺失60秒后清理元数据、缓存和选择；根目录或资料目录不可访问时暂停清理。上一份备份可能暂时包含已删除项。

## 界面

沿用原图库原比例瀑布流、预览大小滑杆、自动加载、最多120张可见卡片。统一搜索名称和标签，顶部文件夹选择与组合筛选并存；颜色匹配优先，名称/文件日期/类型排序，颜色/标签/文件夹/形状组合筛选。

单击卡片显示详情；双击图片放大；双击名称和标签原位编辑。卡片提示词双击编辑，详情及放大框提示词单击编辑；点击外部未修改则退出，已修改询问保存。名称保存会重命名真实图片，不覆盖同名文件。右侧详情可拖动宽度。

选图不限制六张。顶部缩略图按比例显示，多图横向滚动；悬停展开与卡片同宽的信息预览，始终显示名称、标签和提示词，并出现取消按钮。

## Skill规则

选中不等于生成。可以让Codex读取文件、分析提示词、分析配色或按要求创作。生成默认只借鉴提示词写法，明确要求用图片作参考时才传原图。分析不自动保存；明确要求保存后使用工具更新。离线指图库不依赖Eagle和互联网，Codex分析与生图仍需要相应在线服务。

## 安装与维护

安装包解压后双击“安装插件.cmd”。需要Windows、Python3.10+和Codex CLI。安装脚本创建独立Python运行环境并安装Pillow（首次安装可能联网，优先清华镜像，失败回退官方PyPI），不会修改Eagle插件。日常图库运行不联网。安装后新建任务以加载Skill。

元数据损坏时停止读取，不覆盖损坏文件。可从“图库资料/元数据备份/素材信息.json.previous”恢复，先关闭本插件服务再操作。重复图片自动关联歧义需要后续人工确认，不承诺自动匹配所有外部改动。
