# 1.1.0 发布说明

小红书素材原先仅在本地图库中，单独复制图片无法在朋友的图库中带回提示词与标签。本版随完整安装包提供2169张原图与完整资料，并新增独立导入按钮；保留原有541张 image2.5参考。

每张小红书素材包含中文名称、提示词、标签、作者、笔记来源、使用条件或原词差异说明，以及SHA-256。另提供2169份同名TXT，未安装Codex也可阅读。只导出此次素材的相关资料，不发布本机运行配置、缓存、账号登录信息、任务记录、采集脚本或其他图库。

Windows后台启动同步本地已使用的控制台隐藏修复：仅使用 CREATE_NO_WINDOW，不改变服务归属和退出机制。安装器继续备份旧插件，保留自己的图库；当前任务只更新发布仓库，没有替换用户运行中的插件和图库。

## 验证

- 49项插件自动化测试通过，3项Windows进程生命周期测试通过。
- 独立临时图库的HTTP服务实测：首次分别导入541与2169张；2710张原始字节、名称、标签、提示词逐条一致，2169条小红书作者与来源资料一致。
- 重启读取资料正常；重复导入2169张全部跳过；模拟朋友独立编辑后再导入，保留其提示词修改。
- 未知素材集路径返回400，不能借导入入口选择任意目录。
- 网页JavaScript语法、安装前检查通过；安装前检查不是重新安装，未改动用户的插件注册和运行配置。
- 公开资料包数量、同名TXT、原图SHA-256、来源与隐私排除项已核对。详细结果见 XHS_RELEASE_VALIDATION.json。

尚未在一台全新电脑上从零安装，也没有逐项人工验收所有网页交互；以上结果限定于自动化与独立HTTP实测范围。
