# 安装与排错

## 推荐方式

完整解压下载包，双击根目录“安装插件.cmd”。无需让 Codex 自动安装，也无需创建新的 Codex 启动器。使用你自己的普通 Windows 账号，安装路径随用户目录自动生成。

如果 Codex 有真实终端工具，也可以让它阅读本仓库 AGENTS.md 和 README.md，再在安装包根目录执行 `python -X utf8 install.py`。如果工具调用变成聊天文字或它说没有终端能力，请直接双击安装文件，不要把那段回复当成安装日志。

## 环境要求

- Windows；Python 3.10+，安装 Python 时启用 PATH，安装后重新打开终端。
- Codex 桌面客户端，以及在终端可运行的 Codex CLI。先在普通命令提示符中运行 `codex --version` 和 `codex plugin add --help`。缺少 CLI 时按 [官方 Codex 仓库](https://github.com/openai/codex) 的安装说明安装；已有 Node.js/npm 时可使用 `npm install -g @openai/codex`。
- 首次安装 Pillow 需要可用网络。安装器先尝试清华镜像，再回退 PyPI；不修改系统 Python 包。

## 安装步骤的区别

`python -X utf8 install.py --check` 只检查必要文件、Python 和 CLI 插件命令。它不会完成安装，不测试缓存目录写权限，也不测试图库连接。

正式安装会备份已有插件、复制文件、生成本机 MCP 路径、更新缓存版本并注册插件，最后回读 installed/enabled 状态。只有正式安装全部完成才显示成功。新建任务加载新 Skill；插件列表没有刷新时可保存工作后重启 Codex。

## 常见问题

| 现象 | 处理 |
|---|---|
| 没有 python 或 codex 命令 | 安装对应程序并重新打开终端；桌面客户端存在不等于 CLI 已加入 PATH。 |
| codex.ps1 被执行策略阻止 | 最新安装器直接调用 codex.cmd，避免 PowerShell 二次解析。无需全局降低执行策略。 |
| Codex 对话说没有终端/工具调用变成文字 | 还没开始安装。在 Windows 文件管理器双击安装插件.cmd。 |
| 沙箱拒绝写 plugins/cache | 在普通 Windows 终端或双击安装器执行，不要重复在同一个受限会话中尝试。若仍失败，保留真实原始报错。 |
| 源文件已经复制但最后注册失败 | 若个人 marketplace 已准备好，可在普通 CMD 执行 `codex plugin add offline-image-library@personal --json`；自定义市场须用真实市场名称。 |
| 插件列表没有出现 | 在普通 CMD 运行 `codex plugin list --json`，检查 `offline-image-library` 的 installed/enabled。已安装时新建任务或重启客户端，不要反复复制文件。 |
| 页面打不开 | 让 Codex 调用插件的打开工具来启动服务，不要只粘贴网址。端口 18766 被占用时保留日志，勿结束不明进程。 |
| Pillow 安装失败 | 检查安装窗口中镜像与官方源的完整错误，不要把“预检查通过”当作依赖已装好。 |
| 选了图但另一个对话读不到 | 选择按任务隔离；在目标对话重新打开图库并选择，不复制旧 task 地址。 |
| 反推保存报冲突 | 先重新读取资料核对目标，不换 requestId 盲目重试；不要覆盖独立编辑。 |

无法解决时，提交安装窗口完整输出、Python/CLI版本和实际失败步骤。不要提供令牌、私人提示词或整份私人图库。

## 升级

下载最新完整包、完整解压，再运行安装器。它覆盖插件程序并保留旧程序备份，不会替换自己的图库。新建 Codex 任务加载新版。若本地网页服务已在运行，应在确认无待保存编辑后重启对应插件服务，让后端读取新代码；不要结束 Eagle、离线版或其他任务的不明进程。

## 视频依赖

安装 FFmpeg 的 Windows 构建，并把 ffmpeg.exe 和 ffprobe.exe 加入 PATH。官方入口：https://ffmpeg.org/download.html#build-windows。安装后重开本插件服务。视频无法读取时会保留原文件和已有资料，不以缩略图冒充视频。生成本地播放缓存时原文件不变。

## 随插件发布的参考素材

完整仓库安装包随附 `plugin/assets/image2.5参考`：541 张原图及 `manifest.json` 中的名称、标签和完整提示词。安装器复制这些随附素材并校验原图 SHA-256；安装后选择自己的图库，点击“导入随附参考素材”，即可导入平铺的 `image2.5参考` 文件夹。相同内容跳过；同名不同内容保留并另起文件名；导入不会覆盖已有修改。

请下载 GitHub 完整仓库 main.zip，素材随该安装包发布；旧 downloads 目录的小安装包不再作为发布入口。随附图片和提示词用于参考，其权利仍属于原作者，随附不构成额外授权。
